# Self-Driving Car

An AI-based self-driving car simulation built using Python and Pygame.

This project demonstrates a simple autonomous driving system using rule-based AI logic for lane switching and obstacle avoidance in a 2D environment.

---

## Features

- 2D self-driving car simulation
- Lane-based road system
- Random obstacle generation
- Rule-based AI movement
- Collision detection
- Real-time animation using Pygame

---

## Tech Stack

- Python
- Pygame

## How to Run

### 1. Clone the repository
```
git clone https://github.com/samoff04/Self-Driving-Car.git  
cd Self-Driving-Car  
```
### 2. Install dependencies
```
pip install pygame  
```
### 3. Run the project
```
python main.py  
```
